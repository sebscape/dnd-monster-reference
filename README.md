# Critter Codex

A 5E-compatible monster reference for game masters: the 330 monsters of the SRD 5.2.1, plus your own custom monsters and artwork, saved in your browser.

Live at https://critter-codex.c2ma.com. Companion app: [Scrap Sheet](https://scrap-sheet.c2ma.com), a battle tracker.
